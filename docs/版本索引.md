## 新增版本

1. 使用 `_templates/版本研究记录.md` 新建 `versions/<REGION>/<VERSION>.md`。
2. 核实包名、`versionName`、`versionCode`、SHA256、ABI、数据来源和游戏资源版号。
3. 版本间数据必须通过可验证的 ID/路径映射与哈希对照；CHN 与国际版隔离。
4. 别将文件名或来源渠道声明当作已验证的版本号。
