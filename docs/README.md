**打开方式：** `git clone https://github.com/969981/PVZ2_Resources.git` 后，在 Obsidian 选择「打开本地文件夹作为仓库 / Open folder as vault」，路径选择 **`PVZ2_Resources/docs`**，然后打开 `00-知识库首页.md`。已有 Markdown 文件无需导入或转换。

此知识库只收纳研究笔记和少量授权图表；大型游戏资源、原始 APK、解包生成物不得纳入 Git。有关研究证据的具体限制请见 [研究证据规范](研究证据规范.md) 与仓库根目录 [AGENTS.md](../AGENTS.md)。
