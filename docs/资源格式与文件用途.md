# PVZ2 资源格式与文件用途

返回 [[00-知识库首页]] · [[文件目录与职责]] · [[解包操作手册]] · [[FORMATS]]

> [!important] “存在”与“解码成功”分开
> 本文的格式含义来自样本头部、仓库解包器、后续实测和参考工具。**已提取内部文件**不等于所有纹理都已得到 PNG，也不等于动画、音频、玩法参数已经完整解析。

## 1. 从包裹到资源的分层

```text
.apk (ZIP)
  ├── assets/*.rsb.smf  -> RSLB v1 (LZMA blocks)
  │                         -> *.rsb (RSB v4 / magic 1bsr)
  │                            -> RSGP groups (magic pgsr)
  │                               -> resources / members
  │                                  ├── *.rton -> *.json [已成功一部分]
  │                                  ├── *.ptx  -> *.png  [待执行/验证]
  │                                  ├── *.pam / Reanim  -> 动画结构 [待执行/验证]
  │                                  └── *.bnk  -> 音频索引/解码 [待执行/验证]
  ├── assets/properties/*.rton.smf -> 直接 RTON -> JSON [18/18]
  ├── assets/*.rsb.tag.smf        -> 标签/伴随数据（用途待核对）
  └── lib/*/libSrc.so             -> 游戏本地代码 ELF
```

## 2. 扩展名 / 魔数 / 用途 / 解包处理

| 文件类型 | 已知或预期结构 | 通常的作用 | 处理方法 / 验证边界 |
|---|---|---|---|
| `.7z.001`~`.088` | 7-Zip 连续分卷 | 仓库保存的原始安装包副本 | 从 `.001` 用 7z 还原，核对完整 APK SHA256 |
| `.apk` | ZIP | Android 应用与内置资源 | Python `zipfile` 枚举；切勿以 ZIP 解压等于资源解码 |
| `.rsb.smf` | 外层实测魔数 `RSLB` | 33 个资源包的压缩外壳 | `unpack_smf.py` / `parallel_unpack.py`，得到 `.rsb` |
| `.rsb` | `1bsr`，RSB v4 | RSGP 组表与资源包 | `extract_rsg_groups.py` 或 CN Resource_Tool |
| `.rsg` | `pgsr`，RSGP 资源组 | 内部成员封装 | 用 CN Resource_Tool 解出内部条目；`extract_rsg_groups.py` 仅切组 |
| `.rton.smf` | 实测开头 `RTON` | APK 顶层直接配置，不需先展开 RSLB | Stage 1 按原字节复制，Resource_Tool 再转 JSON |
| `.rton`、`.rtom` | RTON 类型二进制对象候选 | 资源元数据、关卡/植物/僵尸等配置 | 实样转换为 JSON；未知或加密文件分开登记 |
| `.rsb.tag.smf` | 未充分逆向的伴随数据 | 可能涉及资源包标签/索引 | 先原样保留，不假定具体键和值 |
| `.ptx` | PopCap 纹理像素编码 | 精灵、图标、贴图、图集 | PopStudio/Pvz2Tool 等候选解码器；核实像素格式与索引，目标 PNG |
| `.pam` | PopCap 动画格式 | 时间线/轨道/图层等动画数据 | 使用支持 PAM 的工具进行结构化导出；需校验版本、帧数与引用 |
| `Reanim` | PopCap Reanimation 族 | 骨骼/元素/逐帧变换等 | 导出可检查轨道或播放数据；并非所有输入都与 PAM 同构 |
| `.bnk` | 音频 bank 格式候选 | 资源中音频内容与引用 | 先判断格式/版本，再导出索引及必要音频；不可直接声称全部 Wwise 已还原 |
| `.so` | ELF | ARM 原生逻辑、资源读取、玩法判定 | IDA/Ghidra/GDB 独立研究；与静态资源解析分开 |
| `.json` | UTF-8 等文本表示 | RTON 对象解析结果、审计报告 | JSON 语法有效≠每个字段语义正确 |
| `.csv` / SQLite | 二次整理结果 | 植物/僵尸/技能/波次/名称关系表 | 必须保留原路径、原始字段、版本、状态，当前属于后续工作 |

RSB/RSGP 资源语义、魔数和偏移的更细粒度技术描述见 [[FORMATS]]。外部工具支持范围详见 [PopStudio](https://github.com/PopGameTool/PopStudio) 和 [Pvz2Tool](https://github.com/DreamMoonCai/Pvz2Tool)；工具具备功能不代表本版本每个文件都已通过实样回读。

## 3. RSLB 的关键结构与提取注意点

CHN 4.2.8 样本观察到：
- `0x00`：`RSLB`，`0x04`：版本 1。
- 固定 `0x30`（48 字节）头，块描述符为 `0x14`（20 字节），相邻块间带 `0x10`（16 字节）链接。
- 压缩块使用带 5 字节参数的 LZMA1 数据；解码器须以声明长度和每块边界作为校验依据。
- 输出先验证魔数 `1bsr`、RSB v4、组偏移和文件长度，再继续操作；单块测试不能代表多块文件全部通过。
- 上述结构为**本版本已实样验证**的规则，不应无条件用于其他国服/国际版版本。

## 4. 资源包名称提供线索，但不是字段解释

| 名称模式（实见/已记录） | 分析优先级 | 不可直接推断 |
|---|---|---|
| `init.rsb.smf` | 初始化与资源索引候选 | 内部全部是初始化配置 |
| `plant1/2/3.rsb.smf` | 植物贴图、动画、配置的检索入口 | 全部植物数值、技能都在其中 |
| `zombie1/2/3.rsb.smf` | 僵尸素材及行为相关资源入口 | 已获得完整僵尸 AI |
| `dino.rsb.smf` | 小体积真实测试样例 | 代表其他大型包完全相同 |
| `update`、`dynamic`、`world` 相关包名 | 更新资源、动态内容、世界素材检索 | 所有版本内容已覆盖 |

**实测样例：`dino.rsb`** → 12 个 RSGP → 30 个内部文件（1 JSON、22 PAM、5 PTX、2 BNK）。这是可追溯样本的成员分类，不是所有 PAM/PTX/BNK 已经完成转换的声明。见 [[versions/CHN/4.2.8-parallel-unpack-results]]。

## 5. 后续构建可查询的游戏资源数据库

建议以 **源文件路径 → RSB → RSGP → 内部路径 → 格式 → 转换文件 → 语义实体** 为主链，目标数据包括：

- 植物：原始 ID、配置路径、阳光、冷却、生命/伤害原始字段及单位、官方简体中文名称。
- 僵尸：原始 ID、血量、移动与特殊行为配置引用；运行时 AI 另行验证。
- 世界/关卡：世界 ID、关卡 ID、模式、波次、刷怪、环境和奖励外键。
- 技能/子弹/动画：技能 ID、触发条件候选、关联动作与贴图路径。
- 本地化：语言代码、text key、实际字符串及来源版本；绝不跨区猜测名称。
- 失败资源：格式、原路径、源 SHA256、未支持原因和可重试状态。

以上字段是**研究规划**，不是已经验证的游戏原始字段名。具体表契约参阅 [[SCHEMAS]]。
