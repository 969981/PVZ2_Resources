## 写作规则

- 用 `_templates/` 创建笔记，使用 YAML Properties、`[[双向链接]]` 和原始 SHA256/工具 commit/证据级别。
- 所有阶段的文件数量、成功/失败范围要写明具体来源；解析到 JSON 不等于验证游戏运行行为。
- 纹理、音频和游戏源文件不得被当作 Git 文档提交；Actions Artifacts 也不等于 Git 历史。
