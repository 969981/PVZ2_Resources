## 文档约定

1. 一篇笔记只解决一个主题；版本实测记录放 `versions/<地区>/<版本>.md`。
2. 新笔记使用 `_templates/` 中的模板，填写 YAML Properties、证据来源、可复现实验、未解决问题。
3. 用 `[[双向链接]]` 关联笔记，图片统一放 `_attachments/`；不把 APK、游戏资产或巨型二进制放进文档仓库。
4. 状态与实验结论以原始文件、SHA256、工具版本、输出报告为准，不以 Obsidian 标签代替验证。
5. 目录适配 Obsidian，但普通 Markdown 内容保持 GitHub 可阅读；本页也可从 [docs/README.md](README.md) 进入。
