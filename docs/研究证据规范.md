# 研究证据规范

返回 [[00-知识库首页]] · 字段规范 [[SCHEMAS]]

## 证据级别（对应现有仓库用语）

| 状态 | 可证明内容 | 不能据此证明 |
|---|---|---|
| `inventory-only` | 文件路径、数量、长度、整体哈希等清单事实 | 文件内容已解析 |
| `header-identified` | 实测魔数、头字段、部分结构 | 全文件可正确解码 |
| `synthetic-tested` | 代码通过合成样本断言 | 真实 APK 资源兼容 |
| `real-sample-tested` | 特定真实样本、特定工具参数的结果 | 同格式所有资源均成功 |
| `decoded` | 指定对象成功转换为可检查结构 | 游戏语义必然正确 |
| `validated` | 完整性/回读/交叉验证通过，范围明确 | 超出验证范围的运行时行为 |
| `unresolved` | 已知未知/失败/待确认 | 成功或功能已实现 |

## 每条结论至少包含

- **观察**：原始路径、地区/版本、SHA256、文件偏移或字段、输出。
- **方法**：工具名、版本/commit、运行命令、参数、测试环境。
- **范围**：单一文件/样本数量/完整分母；明确已成功、失败、跳过、未知。
- **推断**：与观察区分；说明假设和可能的其他解释。
- **复核**：回读或重新解码、相同哈希/结构检验；必要时运行时证据。
- **下一步**：可执行的验证动作，而非空泛“已经完成”。

## 数据使用界限

- 不能仅凭 `plant*.rsb.smf` 命名断言已解析植物图鉴、技能、伤害数值。
- 不混淆 RSLB 外层成功与 RSGP 内层、RTON JSON、贴图像素的实际完成。
- 不把 header 中声明的未压缩大小写成真实解压结果。
- CHN 与国际版拆分核对，游戏内文本只能标为实际来源的语言。
- 运行时代码、配置字段和研究者推测分开记载；没有证据时用 `unresolved`。
- 不在公开库上传游戏文件、APK、私钥、用户存档和令牌。
