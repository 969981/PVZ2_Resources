# 原版 APK、原代码重签名和本地登录实验的可比性

> [!warning] 仍无离线畅玩成品
> 此页只记录可追溯的实际 Android 11 飞行模式运行结果。**安装、签名通过、ZIP 条目未变、源码扫描通过均不代表能够进入原版主菜单**。尚未完成第一关，也未在原版引擎上读回原版存档。

## 唯一原版基线

- 中国版 4.2.8 原始 APK SHA256：`64b0f2cddb6221baf35fb32d4a0f6e64153428edf5ee5922beddb9726bedbda4`。
- Android 测试包名：`com.popcap.pvz2cthdbk`。
- 最早未改原版 APK 在飞行模式中接受隐私条款后开始本地解压，约 600 秒到达拓维手机登录；不等于离线进入游戏。详见 [[18-离线单机里程碑与验收台账-2026-11-07]]。

重签名的 APK **没有成功进入资源解压并保持原版流程**。目前尚不能区分签名兼容、JNI 状态、副作用、原包 v1/v2 签名或模拟器设备差异。原因不允许从单次退出时刻直接猜测。

## 新增匹配实验

- 同 SHA 原版 vs 直接重签名：`.github/workflows/pvz2-offline-original-vs-resign-ab.yml`。
- 两台新建 Android 11 AVD、相同架构/分辨率/飞行模式、相同启动等待与可验证隐私弹窗识别。
- 原版签名候选代码审计：`scripts/offline/signing_integrity_census.py`，工作流 `.github/workflows/pvz2-offline-integrity-audit.yml`。 [实际 #42356176033](https://github.com/969981/PVZ2_Resources/actions/runs/42356176033) 扫描 7,805 个真实 JADX Java 源码，找出 124 个含包签名 API 提示的文件、60 个含主动退出 API 提示的文件，交集 4 个（其中 `AndroidGameApp.java`、`TwOfflineSDK/tools/CrashHandler.java`）。
- 这些是静态文本调用点，不等于发现校验失败分支。只有同设备同流程动态差异能够继续缩小范围。

## 最终必须逐项真实验收

1. 飞行模式下原版主菜单真正显示且交互有效；
2. 原版第一关运行、胜利结算并写入进度；
3. 退出进程、重新启动后恢复同一玩家及关卡进度；
4. 原版存档文件经原版引擎读取，不能用独立 LocalProfileStore 测试替代；
5. 不依赖网络，也不伪造在线账号、支付或服务端权益。

没有以上四项证据时，输出标记 `UNVERIFIED`，不命名为发布版。
