# 国服 4.2.8 源码还原与 APK 实际构筑

> [!warning] 不等于原始游戏源码或离线畅玩
> DEX 的 Smali 可以回编；Java 是 JADX 生成的参考源码；`libSrc.so` 等原生 SO 只能保留机器码与反汇编结果，**无法无损还原厂商原始 C++ 源码**。即使构建成功，主菜单、第一关和原版存档的验收仍独立进行。

## 已有原版证据

- 源 APK SHA256：`64b0f2cddb6221baf35fb32d4a0f6e64153428edf5ee5922beddb9726bedbda4`。
- 六个 `classes*.dex`，28 份原生 SO。
- 现有 [DEX 反编译审计](https://github.com/969981/PVZ2_Resources/actions/runs/42333586188) 恢复 7,805 个 Java 文件，部分 JADX 类反编译报错。
- [原始APK与直接重签A/B](https://github.com/969981/PVZ2_Resources/actions/runs/42356143127)：原版同意隐私条款后 +10/+30/+60/+120 秒均存活；重签名原版 +10 秒已经退出。说明改 Smali 和 APKTool 之外仍有一条签名兼容门槛。

## 已提交的可重复流程

- `scripts/offline/reconstruct_ch428_project.sh`：从确切 SHA 的 APK 流式提取所有非签名成员，并保证全部六 DEX 结构有效。
- `Reconstructed/CHN_4.2.8/README.md`：完整的临时项目层级、命令及证据边界。
- `.github/workflows/pvz2-offline-reconstructed-apk-build.yml`：从仓库里 88 个原始压缩分卷恢复 APK → 固定版本 JADX 和 APKTool → 六 DEX 完整解包 → Smali 回编 → 原始资产/原生库透传 → zipalign/apksigner → Android 11 飞行模式安装观察。

## 六个独立验收门槛

| 门槛 | 核实方式 |
| --- | --- |
| 六 DEX 原始文件 | APK ZIP 索引、DEX magic、class_defs 和 SHA |
| Java/Smali 参考源码 | 文件数、ADB 包名、来源 SHA，JADX 错误独立列出 |
| 六 DEX 真正回编 | APKTool build 的 DEX 实际产物与 class_defs 逐个一致 |
| 原始游戏内容完整 | 新 APK 除 DEX/签名外全部 ZIP 成员 CRC 和 size 不变 |
| APK 可安装启动 | 真实 Android 11 + 飞行模式安装、启动与隐私同意 |
| 游戏真正可玩且能读档 | 原版主菜单、第一关胜利结算、退出重启后的**原版**存档，三项独立证据 |

其中前四项是代码构筑，第五是设备兼容性测试，第六才是最终单机目标。任何环节失败应保留具体日志，不得由构建工具报告覆盖。

## 限制和下一步

`PVZ2_Resources` 当前是公开仓库。默认脚本不上传原始游戏素材、反编译完整 Java/Smali、签名 APK、账号数据和原版存档；如需同步完整工程，请创建并授权一个允许存放这些内容的**私有目标仓库**，再按版权与文件大小限制同步。公开仓库提交原创脚本、版本锁定、解析索引与不包含游戏字节的验收报告。

第 5 秒游戏仍在前台运行，第 25 秒游戏进程已经退出，60 秒和 120 秒仍处于退出状态。结合 [原版与重签名对照 #42356143127](https://github.com/969981/PVZ2_Resources/actions/runs/42356143127)，这表明修改签名触发了渠道／完整性相关的启动阻挡；尚不能仅凭弹窗确定实际验签函数和具体证书判断。

> [!warning] 构建通过不代表离线游戏通过
> 这次验证了可重新打包的完整 **Dalvik/Smali 代码** 和二进制资源，但**没有恢复原版 C++ 源文件**，也没有成功进入主菜单、打完第一关或读回原版存档。完整恢复文件和 APK 仅在本次 Actions 的临时工作目录生成，未提交到公开 Git 树，也未作为公开 Artifacts 发布。

**后续代码级定位重点：** 精确搜索 `盗版游戏随时可能会崩溃` 相关 DEX 字符串引用，分析弹窗回调是否终止进程；与原始签名 APK 做路径对照，然后再处理脱离拓维服务器时引擎所需的本地玩家状态。不能把简单跳过弹窗视为验收成功。
