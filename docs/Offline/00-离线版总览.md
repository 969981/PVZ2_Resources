# 国服 4.2.8 离线版总览

> [!warning] 当前不是可游玩的离线 APK
> 已完成 **M0 真实 APK 静态审计**并提供 **M1 ADB 取证工具**；未拿到目标机运行日志，未完成真实网络调用追踪，也没有任何声称有效的离线启动补丁。

## 目标与边界

保留原版战斗引擎、植物僵尸表现、中文版关卡配置。替换经真实调用链确认的必要远程依赖，使个人测试副本在飞行模式下能够启动、完成关卡、保存并重新载入。仅在已有本地内容支持的情况下逐步恢复任务、商店展示和活动。禁止虚构线上资源或模拟付费交易；不发布商业游戏 APK/素材。

## 15 分钟离线启动结果：已进入拓维登录 UI

- [[13-解压完成后的拓维登录阻塞]]：真实飞行模式模拟器在约 600 秒完成本地解压，出现手机号、短信验证码和账号密码登录；900 秒仍停留该画面。没有看到游客入口。

- [[12-Ghidra原生调用图与离线分支]] 和 `scripts/offline/inspect_login_flow.py` 用于补足代码调用链；原生关卡开始/结算/存档仍待逐项真实验证。
