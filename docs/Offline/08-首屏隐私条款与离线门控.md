# 国服 4.2.8 离线启动首屏实测：隐私条款

> [!success] 真实模拟器截屏已经确认首屏
> [GitHub Actions #42328405541](https://github.com/969981/PVZ2_Resources/actions/runs/42328405541) 成功完成 SHA256 校验、飞行模式首次安装、启动后 5/30/75 秒的实际屏幕截图和 UIAutomator 层级采集。

## 观察方法

- APK：`PVZ2_4.2.8.apk`，SHA256 `64b0f2cddb6221baf35fb32d4a0f6e64153428edf5ee5922beddb9726bedbda4`。
- Android 11 / API 30、Google APIs x86_64 AVD；`libndk_translation.so` 提供 ARM 原生代码转译。
- 全新安装，在点击任何按钮前开启飞行模式并禁用 Wi-Fi / 移动数据；无账号输入、无网络模拟、无原版 APK 修改。
- 通过 ADB `screencap` 获取三个 2340×1080 PNG；`uiautomator dump` 记录无账号隐私信息的页面文本。
- 证据临时保存在该 Actions 的 `pvz2-chn428-offline-first-screen` Artifact（保留 1 天），原版截图不提交 Git 历史。

## 结论

1. **第一处实际 UI 门控是游戏首次启动的隐私条款，不能归类为联网登录或资源更新失败**。
2. 单凭启动后 75 秒仍在隐私条款界面，不足以断言网络依赖；该屏需要用户选择是否同意。
3. 拒绝与同意具有不同用户授权含义，不能让自动化测试擅自点击“同意”。
4. [拒绝分支实验 #42329166497](https://github.com/969981/PVZ2_Resources/actions/runs/42329166497) 将在确认隐私政策节点后只点击“拒绝”，再截屏记录行为；该实验的实际结果应补充在下方，不提前假定退出或继续。

## 尚未验证
