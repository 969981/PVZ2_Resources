# 国服 4.2.8 离线启动首屏实测：隐私条款

> [!success] 真实模拟器截屏已经确认首屏
> [GitHub Actions #42328405541](https://github.com/969981/PVZ2_Resources/actions/runs/42328405541) 成功完成 SHA256 校验、飞行模式首次安装、启动后 5/30/75 秒的实际屏幕截图和 UIAutomator 层级采集。

## 观察方法

- APK：`PVZ2_4.2.8.apk`，SHA256 `64b0f2cddb6221baf35fb32d4a0f6e64153428edf5ee5922beddb9726bedbda4`。
- Android 11 / API 30、Google APIs x86_64 AVD；`libndk_translation.so` 提供 ARM 原生代码转译。
- 全新安装，在点击任何按钮前开启飞行模式并禁用 Wi-Fi / 移动数据；无账号输入、无网络模拟、无原版 APK 修改。
- 通过 ADB `screencap` 获取三个 2340×1080 PNG；`uiautomator dump` 记录无账号隐私信息的页面文本。
- 证据临时保存在该 Actions 的 `pvz2-chn428-offline-first-screen` Artifact（保留 1 天），原版截图不提交 Git 历史。

## 结论

1. **第一处实际 UI 门控是游戏首次启动的隐私条款，不能归类为联网登录或资源更新失败**。
2. 单凭启动后 75 秒仍在隐私条款界面，不足以断言网络依赖；该屏需要用户选择是否同意。
3. 拒绝与同意具有不同用户授权含义，不能让自动化测试擅自点击“同意”。
4. [拒绝分支实验 #42329166497](https://github.com/969981/PVZ2_Resources/actions/runs/42329166497) 已真实执行并确认：点击“拒绝”后游戏退回 Android 系统桌面，进程停止；这是 **隐私选择分支行为**，不是网络连接失败。

## 2026-11-07 拒绝分支实测（不曾点击“同意”）

- [Actions #42329166497](https://github.com/969981/PVZ2_Resources/actions/runs/42329166497) **success**：在同一类 Android 11 / ARM 转译模拟器上，用原始 SHA 一致的 APK 重新进行首次安装。
- 先通过 UIAutomator 检测到文本“隐私政策”（492 个 UI 节点），才执行经实样画面校准的“拒绝”位置单击 `adb shell input tap 940 900`。
- 该 ADB 单击返回成功。之后约 7 秒、27 秒的截屏均显示 Android 桌面，不再显示游戏。
- 两次取证时 `process_alive=false`、`foreground=false`。后续 UI 层级为 Android 启动器（Apps list、Messages、Chrome），不是游戏 UI。
- 报告 `refusal_probe.json` 明确记录 `privacy_consent_granted=false`、`privacy_gate_still_visible=false`、`screen_changed_from_privacy=true`。
- 仅记录这一受控测试的后继行为：**拒绝隐私政策导致原版客户端退出**。不能进一步断言登录接口、主线关卡或游戏存档有任何已验证状态。

## 尚未验证

“拒绝”路径已证实不能进入主菜单；尚未测试明确接受隐私条款后的初始化行为。联网服务、资源更新、存档以及任何关卡结算仍未验证。**仍没有已验证的可玩离线 APK。**
