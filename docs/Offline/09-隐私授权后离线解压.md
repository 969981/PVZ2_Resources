# 国服 4.2.8：隐私同意后本地解压的真实证据

> [!important] 尚未进入游戏主菜单
> 首次启动隐私条款真实授权后，游戏进入 EA 启动页面，并在飞行模式下开始解压本地资源。**解压进行中不是“已完成联网绕过”“完整离线畅玩”或“服务器不可用”的证据**。

## 真实设备和来源

- [GitHub Actions #42331223784](https://github.com/969981/PVZ2_Resources/actions/runs/42331223784)：工作流全部成功。
- 输入：`PVZ2_4.2.8.apk`，SHA256 `64b0f2cddb6221baf35fb32d4a0f6e64153428edf5ee5922beddb9726bedbda4`。
- Android 11 / API30，Google APIs x86_64 AVD，ARM 原生库通过 `libndk_translation.so`。
- 仅在一次性测试模拟器中接受隐私条款，且一直处于飞行模式；原始 APK 未修改。
- 隐私条款用真实截图的标题栏、正文、两按钮 8 个 RGB 参考点确认：`matched_reference_colors=8/8`。避免 UIAutomator 未识别 native text 时误判。

## 授权后的截图顺序

| 授权后目标时间 | 真实画面 | 能确定的结论 |
| --- | --- | --- |
| 5 秒 | EA 标志，旋转加载图形 | 已退出隐私弹窗，进入原生启动流程 |
| 25 秒 | 黑色渐变过渡 | 进程仍运行，不能推断崩溃或联网失败 |
| 60 秒 | 文字“解压需要一定时间，请耐心等待”，下方“正在解压文件1/6” | 开始本地资源解压，绿色条约 25%（仅当前文件） |
| 120 秒 | 同一“文件1/6”解压画面 | 进度条明显前进到约 54%（仅当前文件），不是总进度 |

这里的约 25%、54% 来自截图第 920 行绿色进度条的近似像素占比；“正在解压文件1/6”的数字由实际画面读取，**没有声称对应仓库 33 个 RSB 中的哪六个文件**。

## 运行状态

- `consent_clicked=true`，`offline_after_consent=true`，`privacy_gate_still_visible=false`。
- 四个时间点游戏均存活并在前台。
- 7000 条 logcat 采样范围内，没有匹配到 Java FATAL、原生 Fatal signal、动态库缺失、DNS、Connection refused、SocketTimeout、SSLHandshake 或 ANR 指示。
- 不等于全量运行时网络代码已审计，也不代表所有事件和动态资源都存在。

## 接下来需要闭合什么？

**优先级一：解压完整性。** 测试 10～15 分钟长启动，记录若干定时 PNG、`df -k /data` 数据分区空间、游戏目录可访问时的 `du -sk`，区分正常慢解压、空间不足、转译性能下降和资源校验失败。

新增 `scripts/offline/extraction_monitor.py` 与 `.github/workflows/pvz2-offline-extraction-monitor.yml` 完成这一实验。成功的工作流只代表监测程序执行成功，**不等于游戏能离线通关**。

**优先级二：越过解压后确认页面。** 只有解压完成，再区分游戏菜单/实名认证/网络更新/登录/资源缺失；对于未观察到的服务调用不写死或伪造返回。

**优先级三：本地进度。** 关卡结算 → 退出 → 重启 → 读取同一存档，通过同一 APK Build 的文件变化和游戏状态两边对账。
