# 关卡与内容恢复

本库有已记录的 33/33 RSB、2,964/2,964 RSGP 及 14,869 个内部资源文件，但这不是“全游戏已完全离线恢复”的证据。来源详见 [[versions/CHN/4.2.8-parallel-unpack-results]]。

## 数据恢复优先级

| 类型 | 优先数据 | 关键验收 |
| --- | --- | --- |
| 关卡 | 世界 ID、关卡 ID、模式、波次、刷怪脚本 | RTON 配置 ↔ 原版实际关卡结果 |
| 植物 | 物种 ID、阳光/冷却/攻击、等级 | 静态属性 ↔ 动态战斗表现 |
| 僵尸 | ID、血量、速度、特技、生成条件 | 波次 ↔ 实际生成数 |
| 本地化 | 官方简体中文文本 key 和对应名称 | 原始 key、版本和语境一致 |
| 纹理与动画 | PTX、PAM、Reanim | 像素/动画轨道及真实运行引用 |
| 音频 | BNK 等资源 | 文件类型、内部成员及关卡调用 |
| 活动 | 本地配置、时间条件和奖励 | 数据齐全且不依赖远端时才开放 |

不要从单独资源包命名断定全部植物/僵尸玩法参数；未解析的媒体与动态下载资源作为缺口单独列出。也不能凭离线模拟修正后的数值，倒推声称是原始国服数据。

## 关联主键与来源

每一个资源、关卡、技能需能回溯到 APK SHA256、RSB/RSGP 链、原始 JSON 路径、字段名、解析器版本与验证状态。正式建立关系前先检查别名、同名资源覆盖和跨版本差异。
