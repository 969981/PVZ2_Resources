# 离线购买回调模拟，不等于真实内购成功

本实验在 PR #64 的独立分支新增 `scripts/offline/offline_iap_mock.py` 与 `tests/test_offline_iap_mock.py`。

- `OfflineMockBilling(test_mode=True)` 对 `test.pvz2.*` 合成商品返回 `MOCK_SUCCESS`，回调只触发一次。
- 显式拒绝真实商品 ID 或关闭测试模式的调用。
- 不接入拓维 SDK、商店、APK/Smali 修改、JNI、本地存档、支付凭证、签名或在线服务器。
- 所有响应固定 `verified_store_transaction=false`、`receipt=null`、`entitlement_granted=false`。
- `python3 scripts/offline/offline_iap_mock.py --output path/to/iap_mock_report.json` 仅输出脱敏合成回调数据；无需原版 APK。

## 真实游戏仍有哪些独立门槛

1. 原版签名、飞行模式被动对照在 420/600 秒停留拓维手机号登录界面，不能声称已离线进入主菜单。
2. 重建签名版在原生启动阶段触发正版警告和主动退出，尚未确认与签名校验相关的具体分支。
3. 购买成功回调的合成测试不能证明原游戏有效支付、免费开放付费商品、进入主菜单、完成第一关或保存进度。
4. 真正宣布离线可玩，仍需要原版引擎主菜单、第一关、结算、停止应用、重新启动读回同一进度的 Android 运行证据。

## 构建发布边界

CI 可以发布原创脚本、测试报告、合成 JSON 和不包含游戏代码的材料；不将商业 APK、原始 `libSrc.so`、反编译商业游戏代码、付费权益绕过改动或商业资源作为开源发行物。真实 APK 构建可在用户合法持有的本地来源和受控实验环境下检验，但不能用编译成功代替运行验收。
