# 国服 4.2.8：素材、数据、关卡还原情况

- 33/33 RSB、2,964/2,964 RSGP 和 14,869 个内部文件已经导出。
- 8,091/8,091 个可解析 RTON 已转成有效 JSON，额外的 18 个顶层 RTON 也成功转换。
- [24 个长期保存 Git 分片的独立 SHA256 恢复核验成功](https://github.com/969981/PVZ2_Resources/actions/runs/42325332349)：RSB 8/8（41 parts，33 files）；RSGP 8/8（41 parts，2,964 files）；Internal 8/8（40 parts，14,869 files）。Git 分片存在并 SHA 通过，不等于素材都已变为通用格式。
