## Git 长期保存状态

GitHub 100 MB 单文件限制通过 64 MiB 分卷规避，所有 Shard 均采用 tar.zst、各部分 SHA256、总归档 SHA256、manifest.json。

- [RSB/RSGP/Internal 原始三层长期保存任务](https://github.com/969981/PVZ2_Resources/actions/runs/42320123974)：目标是 24 个独立 shard。状态以 master 对应 manifest 是否存在为准，不以 Actions Artifacts 的存在代替。
- [PNG/PAM/WEM 媒体 Git 归档任务](https://github.com/969981/PVZ2_Resources/actions/runs/42323232965)：目标 8 个 Media 与两个 MediaSpecial，按不超过六个 64 MiB 文件每批独立推送。
- Git 还原使用 scripts/archive/restore_git_shard.py 的 verify-only / restore 子命令。
- 尚未提交完成的分片不算永久交付；Actions 原始产物保留期短，需要持续验证 Git 存储。
- 本仓库为公开状态，从游戏提取的原始资源可能受版权保护。

相关 Obsidian 笔记：[[4.2.8-parallel-unpack-results]]、[[4.2.8-git-archive]]。
