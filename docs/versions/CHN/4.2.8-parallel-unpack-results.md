# PvZ2 国服 v4.2.8：并发全量解包实测

本报告记录了 **2026-11-06（UTC）** GitHub Actions 上对仓库原有 88 个 7z 分卷恢复出的原始 Android APK 的实际处理结果。所有数量来自当次 Actions 日志与附带的 JSON 审计，不是预计值或模拟测试数据。

## 样本与输入校验
- APK: PVZ2_4.2.8.apk，2,271,168,082 字节。
- SHA256: 64b0f2cddb6221baf35fb32d4a0f6e64153428edf5ee5922beddb9726bedbda4
- 源分卷: ROMS/CHN/V4.2.8/PVZ2_4.2.8.7z.001～.088，88 个，压缩数据合计 2,248,514,240 字节。
- Actions 使用 7z 恢复 APK，sha256sum 明确报告 OK。
- 本次测试源为国服 APK，**不是**完整安装后从服务器下载的所有动态资源；相关在线下载内容不在本次范围。

## 第一层：APK / RSLB → RSB
- [成功的 Stage 1 任务 #42256393599](https://github.com/969981/PVZ2_Resources/actions/runs/42256393599)
- RSLB 解压器修复了真实样本里遇到的块描述符问题（固定 0x30 字节头、0x14 字节描述符、块间 0x10 字节链接）。
- 33 个 RSLB → 33 个有效 1bsr / RSB v4 文件。
- 额外保留 18 个直接 RTON 和 38 个其他 SMF/标签文件。
- 89/89 项成功，错误 0；初次 dino 探针校验通过的两项在全量步骤中以 skip-verified 计入成功。
- 原始 RSB 解压数据总大小 **5,913,571,328 字节**（约 5.51 GiB）。
- 产物：8 个 RSB 分片 Artifacts + 1 个 SMF/RTON 审计包。

## 第二层：RSB → RSGP
- [成功的 Stage 2 任务 #42258406327](https://github.com/969981/PVZ2_Resources/actions/runs/42258406327)
- 使用 8 个 Actions 矩阵任务、最多 4 个并发 Job，每个 Job 使用 2 个本地 worker。
- 33 个 RSB 共 **2,964 个 RSGP 资源组**，2,964/2,964 实际导出，错误 0。
- 单独先验证 dino.rsb 的 12 个 RSGP 资源组。
- 输出保留来源 RSB、组名、偏移、长度、SHA256；按 8 个分片分别上传二进制成员和审计索引。
- 该层仅完成资源组导出，不代表已得到可编辑的 PNG、PAM 动画或所有游戏字段。

## 第三层：RSGP → 内部文件 / 可解析 RTON → JSON
- [成功的 Stage 3 任务 #42259266531](https://github.com/969981/PVZ2_Resources/actions/runs/42259266531)
- 解析器来源：[PVZ2-Chinese-Version-Reverse-Tools](https://github.com/lei1737524550/PVZ2-Chinese-Version-Reverse-Tools)，固定 git commit 04f57f42080ef831545c9b2877f81f811f0be4e2。
- 运行环境 Python 3.13，8 个矩阵 Job、并发度最多 4 Job × 每 Job 2 Worker。
- 从 2,964 个组实际提取 **14,869 个内部文件**。
- 其中 **8,091 个可解析 RTON 成功转成 JSON**，最终 JSON 格式有效 8,091、无效 0、大文件跳过校验 0。
- 另外 **6,778 个文件仍保留其原始格式**。包含 PTX 纹理、PAM 动画、BNK 音频等，**未声称**此阶段已经全部解码为 PNG/动画帧/音频。

## APK 顶层直接 RTON 独立解码

## Artifact 下载及保留期限
- Stage 1 下载 8 个 RSB shards + audit。
- Stage 2 下载 8 个 RSGP shards + 8 个 group index + dino smoke。
- Stage 3 下载 8 个 JSON/internal-files shards + 8 个 conversion indexes + dino smoke。
- 直接 RTON 工作流下载 18 JSON 及校验报告。
- 工作流目前使用 **retention-days: 3**；Artifacts 不是永久仓库内容，过期需要重新运行对应任务。不要把“Actions Artifacts 已生成”误记为“全部派生文件已提交 Git 仓库”。

## 未完成及下一层优先级
1. PTX → PNG（检查实际纹理格式、图集切割，像素与贴图索引回读）。
2. PAM / Reanim → 可检查的 JSON、帧序列或 XFL，关联贴图名称和动画时间轴。
3. BNK 与其他媒体格式识别，必要时对音频进行不损失来源信息的转换。
4. 从原生 JSON 建立植物、僵尸、关卡、波次、技能、简体中文文本的结构化 CSV/JSON/SQLite，字段都保留来源路径与版本证据。
5. 所有资源与 APK 条目逐一审计：重复路径、引用断链、未支持格式、版本差异、转换错误。
6. 需要游戏行为和伤害公式证据时，单独分析 ARM64 libSrc.so，不能把静态 JSON 参数等同于已验证运行时行为。

> 验收边界：本次真实完成三层容器解包和可解析 RTON JSON 转换。没有宣称全部 14,869 个成员都已转换到通用媒体格式，也没有宣称已提取完整国服游戏规则数据库。
