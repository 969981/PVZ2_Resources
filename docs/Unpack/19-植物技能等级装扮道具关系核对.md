## 以 PlantType 为唯一正确起点

源：`Internal/shard-05/04_JSON/dynamic/Packages/PACKAGES/PLANTTYPES.json`；已索引 **381 条 PlantType 源记录**，它们不等于 381 个互不重复的游戏内植物。以 `source_file + object_index` 作为主键，`TypeName` 是用于浏览的名称，不足以区分关卡覆盖。

| 需要的资料 | PlantType/属性字段 | 接下来关联的表 |
|---|---|---|
| 中文名 | `TypeName` | LawnStrings 候选匹配，不将其冒充正式图鉴显示 |
| 植物图片 | `PlantResourceGroups`、`PlantPieceImageName` | RTON `group_id` → PNG 图集 `asset_paths.csv`，逐项验证 resource ID |
| 动画 | `PopAnim`、`SecondPopAnimRare` | `PAM_JSON` 路径 → 图集 image-name/裁剪 → 首/中/末帧 |
| 基础属性/等级 | `Properties` | `PlantPropertySheet.PlantLevelStats / PlantStats / MinLevel / MaxLevel` |
| 技能/植物能量豆 | PropertySheet 的 `Actions`、`PlantFoodPlayCount` | `SkillPropertySheet`、`ProjectilePropertySheet` 的 RTID，待跟踪代码 |
| 装扮 | `Avatars`、`AvatarEnabled`、`AvatarPieceImageName`、`ExchangeAvatarCost` | `PLANTNEWAVATARS`、`CollectableAccessoryPieceType`、`PlantAccessoryPropertySheet` |
| 升级/植物碎片 | `PlantPieceImageName`、属性 `PlantLevelStats` | `CollectablePlantUpgradeType` / `CollectableUpgradeType` 等需验证是否对应本植物 |
| 神器和道具 | 相关 RTID、原始 `Artifact* / Collectable*` 类 | `ARTIFACT.json`、`ARTIFACTIMPROVEDPROPERTIES.json`、`COLLECTABLETYPES.json` |

重要：`PlantPropertySheet` 只有 27 条源记录、`PlantLevelStats` 在其中 26 条出现；不能一一当成 381 张独立植物升级表。必须保留 alias 精确引用、多实体复用、未命中与歧义情况。

## 示例：豌豆射手的字段追踪步骤

1. 在 `entities` 查 `type_name='peashooter'`，读取原始 `source_file`、`object_index`、`Properties`、`PopAnim`。
2. 在 `links` 查与 `$.Properties` 相关的记录，只接受 `exact-alias-source-reference` 为可追踪的属性表连接。
3. 从 `level_rows` 查看原始等级数据、阳光 Cost、Hitpoints、冷却、攻击字段，**不要转换为实际输出的攻击力**。
4. 在 `avatars` 看每个装扮引用，再检查 `ancillary_links` 是否找到具体 Collectable/Accessory/Avatar 对象。
5. 从 `assets` 查可直接打开的 PNG 链接及 PAM JSON 源路径。`filename-exact-normalized-candidate` 只能用于查找，不是动画图层关系。
6. 用源 RTON 的 `resource_id`、`atlas_parent_id`、`ax/ay/aw/ah`，PAM image references 和运行时逻辑完成真正素材闭环。

## 进阶和装扮的专门排错

- `Quality`、`Rare` 和 `Profession` 是原字段，不应凭名字推断植物升到哪一阶。
- `Avatars` 数组可能包含多个引用或类型；原始对象数量不能等于拥有装扮数量。
- `NewAvatarGeneralSkillBoost` 属于值得调查的静态加成类，仍需装备条件、优先级、冲突与实际战斗数值验证。
- `CollectableAccessoryPieceType`、`PlantAccessoryPropertySheet` 需要匹配所指植物、碎片、解锁/装备条件。
- `SkillIconImage` 只是原始资源引用，可能尚未解析到独立 PNG 的 Atlas 子矩形。
