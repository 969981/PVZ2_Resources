## 原始 ZombieType 主表

原始 \`ZombieType\` 共 **1,265 条配置记录**，多数位于 \`04_JSON/dynamic/Packages/PACKAGES/LEVELS/*.json\` 或类型配置中。同一 \`TypeName\` 可能在关卡中多次出现，故 source_file + object_index 是主键，不能去重后当作一个已验证游戏物种。

| 研究目标 | 原始字段 | 应做的实际关联 |
|---|---|---|
| 类型与中文名 | \`TypeName\`、\`ZombieClass\` | LawnStrings 和 Almanac 文本（中文候选需实机验证） |
| 静态外观 | \`ResourceGroups\` | 资源 RTON group ID → \`Images/.../zombie1|2|3\` 图集候选 |
| 动画及动作 | \`PopAnim\`、\`AnimRigClass\` | 原始 PAM → PAM JSON → 图层/动画状态 → PNG atlas |
| 生命与速度 | \`Properties\` | \`ZombiePropertySheet.Hitpoints / Speed / EatDPS / AttackDPS\` |
| 等级和数值缩放 | \`ZombieLevelStats\`、\`ZombieStats\`、关卡的 \`ZombieLevel\` | 区分基础属性、关卡等级、难度加成和实际运行时公式 |
| 盔甲/头盔 | \`Helm\`、\`HelmHitpoints\` | 僵尸属性表的装甲字段（不一定等于可装备道具系统） |
| 特殊能力/攻击 | 属性 \`Actions\`、\`ProjectilePropertySheet\`、Zombie-specific Action | 需源码 RTID / 行为脚本查证；不能只按动画 \`SKILL\` 字符串猜 |
| 关卡刷怪 | LevelDefinition → WaveManager → SpawnAction | 同名僵尸的各种来源/生成条件需与遭遇波次外键相连 |

这些是 **PNG 组路径存在** 的证据，尚未证明与某个 ZombieType 配置的一对一外键。僵尸的特殊能力可能由 \`Zombie...ActionProps\`、关卡模块和行为系统共同定义，不能把 \`SkillPropertySheet\` 的植物技能表机械套用到全部僵尸。

> [!warning] 必需的运行时验收
> 选中同一 Build 的一种僵尸，确认 TypeName/关卡实例 -> Properties 读取 -> 具体行为动作 -> PAM animation state -> 正确 atlas 图层，再对账移动速度、生命值、头盔与技能状态。当前静态映射仅保留候选、精确 alias、歧义和 unresolved 记录，不宣布全僵尸实机验收。
