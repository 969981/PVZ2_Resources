## 2026-11-07 进一步修正：削弱历史与原生投射物对象

**先阅读 [[Unpack/23-四株百分比毒历史削弱与原生RTID证据]]。** 新一轮 [原生来源 Actions #42360216027](https://github.com/969981/PVZ2_Resources/actions/runs/42360216027) 已进一步 SHA256 校验 `PLANTTYPES / PROPERTYSHEETS / PROJECTILETYPES / SKILLTYPES` 等 7 份原始配置，提取 52 个原生对象及 68 条静态引用：

- 桑葚当前 `MulberryProps.Level5AttackRate=0.2`、`PlasmaSection=0.2`、`FlashSection=0.6`；按特殊攻击互斥三分支可得到 **4%毒气、12%闪光、4%爆破**；`MulberryGasGrenadeProps.PoisonDamage=20`、`PoisonDuration=10` 与 2021 资料吻合。2020-03-17 旧文章记载 **5%毒气、33%/s、10秒**，有明显变化证据，但**具体削弱版本未找到旧包作源 diff**。
- 药师原生 `ConvallariaChemistProjectileProps.MaximumStackLevel=3`、`PoisonInfos[].PoisonDamage=[1,2,3]`、各5秒；二/三阶毒液生成率候选 `BasicVenomRate=.2`、`AdvancedVenomRate=.3`，**不能混为20%/30%毒伤**。2020/2021玩家记录均是每层1%，没有可靠数据证明毒伤被砍。
- 莲藕原生 `LotusshooterProps.PoisonDamage=1`、`PoisonDuration=3`；投射物 class `LotusPoisonProjectile` 对应 BaseDamage=40/20。**最新4.2.8是否按最大生命值1%结算尚未通过代码验证**；百科记载 2.3.0 的高百分比属 bug 并在后续修正，与2021攻略中的1%说法矛盾。
- 虎头菇五阶技能 RTID `tigerstool_Skill1_Level5` 可确认；原始 `TigerstoolDefault` 属性记录中仍没有找到 10% 毒伤参数，不应把玩家攻略当作原生已证实值。
- `GridItemPoisonMistProps._percentOfMaxHealth=0.2` 的动画是 `POPANIM_EFFECTS_ZOMBIE_RENAI_PERFUMER_POISON`，**不能把该对象擅自指认为桑葚的毒气弹配置**。

## 最大血量毒伤的示例计算（条件模型）

只在原生运行时真正使用目标**最大本体生命值** (H_{max})、且忽略抗性/装甲/减益覆盖的条件下：

[
D_{	ext{tick}} = H_{max}	imes p,qquad
D_{	ext{total}} le H_{max}	imes p	imes T
]

例如五阶桑葚若成立 (p=0.20)、(T=10s)，一个最大 HP 为 27,000,000 的僵尸每秒理论掉 5,400,000 HP，持续有效5秒就能覆盖本体最大生命值；但这**不意味着游戏一定5秒击杀**：中毒触发概率、防具吸伤、分段扣血、帧间隔、毒状态覆盖、Debuff 抗性、伤害上限、BOSS/免疫都会改变结果。

同样，药师的 **3%/秒 × 5秒 = 15%最大生命值** 仅在三层持续且不被刷新/驱散的静态假设下成立，不能当作每次攻击自动扣15%。
