## 芦藜药师：毒素阶段

`ConvallariaChemistDefault@ProjectileTypes`：
- `BaseDamage=30`，`SplashDamage=0`，`SplashRadius=1`。
- `MaximumStackLevel=3`，`MaximumStacksPerLevel=3`，`StacksToAdd=1`。
- `BasicVenomRate=0.2`，`AdvancedVenomRate=0.3`。
- `PoisonInfos` 的三条记录：`(PoisonDamage, PoisonDuration)=(1,5),(2,5),(3,5)`。
- `DamageType=[poison]`，AttachedPAM=`POPANIM_EFFECTS_CONVALLARIACHEMIST_BULLET`，ImpactPAM=`POPANIM_EFFECTS_CONVALLARIACHEMIST_BULLET_HIT`。

**结论：** 三级毒素、1/2/3 的配置和 5 秒持续时间是源证据；1%、2%、3% 最大生命值/秒属于与社区资料一致的**语义假设**，并非原生计算逻辑已经被证实。结合[二阶20%生成7秒毒池、三阶30%的技能资料](https://plantsvszombies.fandom.com/wiki/Lily_of_Pharmacy)，0.2/0.3 **更可能是生成地面毒池概率**，而非“命中施毒概率”。原生调用路径仍待验证。另有 `ConvallariaChemistProps.Level5Rate=0.5`，与五阶50%强化药剂瓶描述吻合；`ConvallariaChemistSuperDefault.BaseDamage=200` 与五阶攻击系数3相乘可得到攻略所述600，但运行时相乘关系尚未验证。

## 桑葚爆破手：两套触发机制

`MulberryDefault@PropertySheets`：
- `SplitGrenadeRate=0.1`，`ImprovedGrenadeBonus=1.0`，可能对应二/三阶的爆破升级，但是否“乘 2”尚无代码证据。
- `Level5AttackRate=0.2`、`PlasmaSection=0.2`、`FlashSection=0.6`。
- **待证假设**：第一阶段以 `0.2` 进入五阶特殊弹药分支；第二阶段分配三弹药区间 `0.2/0.6/0.2`，因此等离子 4%、闪光 12%、毒气 4%。该假设符合多个攻略资料，但没有证明实际 RNG API、门槛比较方式或分支顺序。
- `GiantGasGrenade` 的 `PoisonDamage=20`、`PoisonDuration=10` 与社区“20% 最大生命值/秒、10 秒”说法一致；**尚未证明其单位是最大生命值百分比或每秒扣血**。
- `GiantFlashGrenade.StunDuration=2`，`GiantPlasmaGrenade.BaseDamage=2500`。击飞概率、击飞体型条件和 3×3 碰撞范围不由这几个字段单独证明。

为了防止概率解释误用，假定攻击每 5 秒一次、每发毒气命中独立且概率真为 `p=0.04`：
- 单株 12 发（约 60 秒攻击窗口）至少出现一发的理论概率 `1-(1-0.04)^12=38.729%`。
- 单株等待首发毒气的理论期望 `1/0.04=25 发`，按固定间隔约 125 秒。
- 多株、刷新攻击计时器、无僵尸时不射击、连续状态影响、实际 RNG 实现、事件先后可能改变此模型；这是**条件概率计算**，不是游戏运行测量。

## 运行时验收

1. **原生概率分支**：关联 `PlantMulberry` 的实际战斗 Update/Fire callsite、独立随机数源和 `Level5AttackRate` 的成员偏移；观察同一五阶植物多轮真实发射，计数每个弹药对象类型，记录触发总数、样本分母、游戏状态与版本 SHA。
2. **百分比毒伤**：选取已知生命值/防御的两种非免疫僵尸，通过内部受击函数记录 `maxHP`、`currentHP`、`poison stack`、`deltaHP`、真实计时器；区分 `20` 绝对值、20% 当前生命值、20% 最大生命值。
3. **中毒叠层**：在 1/2/3 层分别测每 tick 扣血、重上毒是否刷新持续时间、不同毒源是否共享堆叠和 3 层上限。
4. **手雷及溅射**：用位置可知的单体／多目标测 `SplashRadius=1 / 2.0736` 对应实际范围；不直接把后者换算成格数。
5. **结果归档**：保存设备、模拟器 ABI、原始 APK SHA、ELF SHA、ASLR 加载基址、战斗前后 HP、事件 timestamp、异常和无效样本；不可用编译成功/静态字段替代实机验收。

## 2026-11-07：地面毒液独立 GridItem 及三弹药命中特效

源：[四株植物的原生对象证据](https://github.com/969981/PVZ2_Resources/blob/master/Catalog/CHN/V4.2.8/poison_nerf_evidence/native_selected_objects.jsonl)，来自已 SHA256 核验的 `PROPERTYSHEETS.json`、`GRIDITEMTYPES.json`、`PROJECTILETYPES.json`；与 [成功 Actions #42360216027](https://github.com/969981/PVZ2_Resources/actions/runs/42360216027) 对应。

- `GRIDITEMTYPES.json` 对象 222：`TypeName=venom`、`GridItemClass=GridItemVenom`、`Properties=RTID(GridItemVenomDefault@PropertySheets)`、`ResourceGroups=["PlantConvallariaChemist"]`。这是药师地面毒液与植物资源的静态显式连接，不是凭名字臆测。
- `PROPERTYSHEETS.json` 对象 1055：`GridItemVenomProps` / `GridItemVenomDefault`；`Lifetime=7`、`VenomTime=2`、`VenomInfos=[1,1.5,2]`、`Height=ground`。
- `ZombieBlacklist=["future_jetpack","future_jetpack_disco","pirate_captain_parrot","seagull","cannon"]`。只有配置层面的排除列表已确认；具体是否仅排除受毒、是否可击中，以及其他飞行/免疫规则仍待原生代码与实机验证。

- `MulberryPlasmaGrenadeProps` / index 632：`AttachedPAM=POPANIM_EFFECTS_MULBERRY_PLASMA`，`ImpactPAM=POPANIM_EFFECTS_MULBERRY_ALL_HIT`，`ImpactPAMAnimationToPlay=r4`，`FlickRate=0.8`。
- `MulberryFlashGrenadeProps` / index 633：`AttachedPAM=POPANIM_EFFECTS_MULBERRY_FLASH`，`ImpactPAMAnimationToPlay=r5`，`StunDuration=2`。
- `MulberryGasGrenadeProps` / index 634：`AttachedPAM=POPANIM_EFFECTS_MULBERRY_GAS`，`ImpactPAMAnimationToPlay=r3`，`PoisonDuration=10`，`PoisonDamage=20`。
- 上述三颗弹药都使用 `DamageFlags` 中的 `shooter`，以及 `CollisionFlags=["griditems","ground_zombies","off_ground_zombies"]`，但这些 flag 并不单独证明对所有目标造成同等伤害或状态。
- 三弹药的 `CollisionRect=(mX=-34.5,mY=-33,mWidth=67.5,mHeight=67.5)` 是投射物碰撞框参数，**不能等同于战斗中爆炸的 3×3 格范围**。应结合命中后的代码和实战格位扫描进行核对。
