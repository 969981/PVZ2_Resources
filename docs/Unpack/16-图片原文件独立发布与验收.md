## 工作流如何保证每张图片是真实可预览文件

1. Media-00～05/07 从已归档的分卷解压，按 Catalog 检查原路径、大小与 SHA256，只提取 .png。
2. Media-06 从源 Actions #42321977158 的 `pvz2-chn-4.2.8-media-6` 恢复，基于已提交的 501 条来源审计选择 .png。
3. 每张 PNG 再以 Pillow 进行 `verify()` 和完整像素 `load()`，检查 SHA256、原路径与实际枚举结果是否一致。
4. 用普通 Git 将 PNG 按每批最多 60 张、300 MiB 推送，遇并发更新则 fetch/rebase/retry；最后才提交本分片的 `PNG-MANIFEST.csv`。
5. 任一分片失败不得默认为成功，已经完成的独立分片可以在下次运行时幂等跳过。

工作流路径：`.github/workflows/pvz2-publish-licensed-png.yml`。
