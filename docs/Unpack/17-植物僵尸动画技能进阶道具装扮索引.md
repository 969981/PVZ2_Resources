现有资料记录原始 PAM **3,847** 份完成结构转换；当前原媒体记录中 Media-00～05/07 有 3,621 份 PAM_JSON，Media-06 实际审计路径包含另外 **226** 份（`3,621 + 226 = 3,847`）。**这不是 3,847 段可直接播放的视频**，且 Media-06 的 PAM JSON 本体仍依赖原 Actions Artifact 恢复；已提交的 `Parsed/` 中同类 JSON 只是原文件的解析元数据。

### 3. 植物进阶/技能详细数值需要看哪些文件

- `Internal/shard-05/04_JSON/dynamic/Packages/PACKAGES/SKILLTYPES.json`：`SkillPropertySheet` **857** 条，具有 `SkillName`、`SkillDescription`、`SkillIconImage`。

- `.../PROJECTILETYPES.json`：已经观察到 `ElectricPeaAdvancedProjectileProps`、`MeteorAdvancedProjectileProps` 等原生类名，但不能将它们无依据地映射成所有植物的进阶技能树。
- `.../PLANTNEWAVATARS.json`：形象与技能加成候选类 `NewAvatarGeneralSkillBoost`、`NewAvatarPetSkillBoost`。应验证装备条件、槽位和加成计算，不要直接套用于全部 `Avatars`。

**下一层关键目标**：提取这几个原生 JSON 的对象内容，而不止索引类名，然后用原始 `alias`、`TypeName`、`resource_id` 建立 `植物 → Avatar → 装扮属性/碎片 → 图集 → PAM → 技能表现` 的可回溯关联。最终玩家面板数值和战斗结果仍需要运行时代码或实机回归。

## 六、专门生成的检索清单

`scripts/catalog/build_visual_semantics.py` 对仓库真实来源索引、八份 PNG MANIFEST、原始 PAM、PAM_JSON、object_classes 和 gameplay SQLite 做只读审计，输出：

```text
Catalog/CHN/V4.2.8/semantic_assets/
├── SUMMARY.json
├── asset_paths.csv
├── animation_atlas_group_candidates.csv
├── skill_item_costume_candidates.csv
├── config_class_candidates.csv
└── gameplay_raw_fields.csv
```

每张表用途：

- `asset_paths.csv`：按 `family`（plant / zombie / ui_or_shared / world_or_effect）、`format`、`shard`、源路径搜索；
- `animation_atlas_group_candidates.csv`：尝试把 `PlantPeashooter_1200` / `PlantPeashooter_Common` 等相同组名归并，**标记 name-only-candidate**，不是已验证图片外键；
- `skill_item_costume_candidates.csv`：按路径中的 `Accessory/Artifact/Skill/PlantFood/LevelUp/Upgrade` 等词搜到的候选图片/动画；
- `config_class_candidates.csv`：源 `objclass` 中与升级、技能、道具、装备等词相关的真实类名、出现量和来源；
- `gameplay_raw_fields.csv`：显示真实 gameplay 对象包含哪些原始字段，以及有多少记录含该字段；
- `SUMMARY.json`：记录每种格式的真实分母和候选组关联数量。

[索引生成工作流](https://github.com/969981/PVZ2_Resources/actions/workflows/pvz2-visual-semantic-catalog.yml)。**工作流 #42354613851 已成功，六份 CSV/JSON 已在 master 可检索**。实测：PNG **1,520**、原始 PAM **3,847**、PAM_JSON **3,847**；路径前缀分组下植物 PNG **344**、僵尸 PNG **412**（是图集文件数，不是物种数），植物 PAM_JSON **1,439**、僵尸 PAM_JSON **884**；有 **1,028** 个同 bundle 的 PNG/PAM_JSON 组名候选对应，另 **359** 个未成对组名；仍须验证资源 ID 和动画 image-name 外键。检出技能/道具/配件等关键字路径候选 **819** 条、对象类候选 **435** 种、原始 gameplay 字段 **384** 项。
