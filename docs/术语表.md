# 术语表

返回 [[00-知识库首页]]

| 名称 | 此项目中的含义 | 注意 |
|---|---|---|
| APK | Android 安装包，ZIP 容器 | 清单和实际可解析内容分开 |
| SMF | 本项目中 APK 的部分资源后缀 | 不能仅凭 `.smf` 后缀推定统一压缩 |
| RSLB | 观察到以 `RSLB` 开头的外层块容器 | 文件头识别不等于完整解压 |
| RSB | 展开 RSLB 后预期的资源容器 | 需要真实 magic/组表验证 |
| RSGP | RSB 内部资源组 | 必须逐组及逐成员审计 |
| RTON | PopCap 二进制对象数据格式 | 有明文/可能加密等不同路径 |
| PTX | 纹理资源 | 转 PNG 需验证像素、尺寸和格式 |
| PAM / Reanim | 动画或序列化资源 | 结构解码与播放验证不同 |
| Stage 0–6 | [[ROADMAP]] 中定义的处理阶段 | 完成状态按明确验收关卡判定 |
| SHA256 | 数据完整性追踪用摘要 | 记录输入与输出，避免跨版本混淆 |

格式细节以 [[FORMATS]] 为准；数据字段以 [[SCHEMAS]] 为准。
